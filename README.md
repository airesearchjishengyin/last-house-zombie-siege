# 最后防线：尸潮围城

一个浏览器里的 AI 战术生存模拟游戏：人类小队由开源 Laya typed-decision checkpoint 选择战术，僵尸按规则追击、绕障和同化。纯规则基线也可以运行。游戏与决策服务均可在本机启动。

## 快速开始

```sh
PORT=8001 python3 server.py
```

打开 http://127.0.0.1:8001。仅体验游戏不需要安装模型；启用 Laya 的方法见 [models/README.md](models/README.md)。首次启动决策服务会下载模型权重。当前模型 checkpoint 尚未针对本游戏进行微调，游戏中的状态到动作定义由项目代码提供。

## 游戏内容

### 地图与任务

- 北岭避难所：外围工事和两侧通道。
- 十字路口：街区建筑与多条迂回路线。
- 废弃工厂：仓库、管线与狭窄通道。
- 回声迷宫：带假岔路、射击孔和多间巢室的环形迷宫。
- 蜂巢地堡：六间密室由窄廊连接，形成交叉火力路线。
- 黑水河谷：河流把地图分成两岸，只有两座桥可以通行；水面允许射击但阻挡移动。
- 自定义地图：待命时点击“编辑地图”，点击空地添加矩形掩体，点击掩体移除，再点编辑按钮结束编辑。掩体自动存入当前浏览器；刷新后重新选择“自定义地图”即可加载。

“导出”保存自定义地图 JSON，“导入”加载它。最多 32 个掩体，单个掩体宽高为 16–240，场地采用 1120 × 690 的坐标系统。任务核心周围保留 50 的通道，边界保留 24。JSON 示例如下：

```json
{"version": 1, "obstacles": [{"x": 214, "y": 333, "w": 52, "h": 38}]}
```

保护种子库：守住核心并完成 6 波尸潮。摧毁母体：从西侧部署，在 360 秒内探索巢穴密室，发现并消灭隐藏在房间中的 900 HP 小型母体；僵尸会在侦察点附近巡逻并在看见人类后追击。有限弹药模式下，单位会在余弹不足时自动前往黄色补给箱，停留 2 秒补满后返回任务路线。

待命时可展开“难度与兵力”，选择轻松/标准/困难或自定义人类数、首波尸数、普通尸血量和每分钟增援数；改动立即重置并作用于接下来的战斗。防守的后续波次会递增，精英尸血量为普通值的 1.65 倍。难度不会在战斗中途修改。

建筑和掩体使用相同的障碍数据进行绘制、寻路与移动碰撞；射击孔和河流使用独立的弹道层：射击孔能让视线/子弹通过但不能让单位通过，河流阻挡移动但允许射击。单位沿障碍拐角寻路；移动会扫过整段位移；子弹比较墙体、僵尸与母体交点，只命中最先遇到的对象。母体位置在发现前不会泄露给导航或画面。

### 决策模型与验证

Laya 从当前合法动作中选择战术：分队搜索、定点压制、侧翼包抄、突击母体、集合补给或环形守卫。动作直接改变队伍分工、路径和目标优先级；画面显示路线、目标和执行人数。候选项依当前可见敌情、母体是否发现、缺弹和队形决定，模型不可选择无可执行目标的命令。当前检查点尚未针对本游戏训练，动作映射不代表完成了游戏专项训练。

检查命令：

```sh
node --check game.js
python3 -m py_compile server.py
node tests/simulation.cjs
```

模拟检查覆盖绕墙、低帧率位移、子弹命中顺序、快速子弹与薄墙、接触同化、地图数据校验、六种地图/任务组合以及最终防守波次获胜。浏览器验证包括进攻、防守、地图编辑持久保存和 JSON 导入/导出。

## 项目文件

- `game.js`、`maps.js`：战斗模拟、地图、战术决策映射和绘制。
- `server.py`：静态文件服务和可选的本地模型 API 代理。
- `models/README.md`：模型来源、许可和本机启动步骤。
- `tests/simulation.cjs`：无浏览器的模拟回归检查。
- `marketing/xiaohongshu/`：小红书图文素材、文案和研究来源。
